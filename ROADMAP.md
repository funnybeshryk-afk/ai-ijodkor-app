- [x] Инициализация Supabase через --dart-define, `.env`-примеры в README
- [x] Локализация uz/ru + переключатель языка (сохраняется между запусками)
- [x] Экран входа (email + пароль), выход, восстановление пароля

- [x] Тема и базовые виджеты

- [x] GitHub Actions: flutter analyze + test + сборка debug APK (с секретами SUPABASE_* — сборка с ключами)

## Этап 2 — Ученик
- [x] Главная: баллы, прогресс, следующий урок
- [x] Уроки по модулям (только доступные через lesson_access), статусы прогресса
- [x] Экран урока: текст, видео/ссылка (content_url), отметка «просмотрено»
- [x] Тест к уроку (проверка на сервере, без correct_answer на клиенте) — RPC
      `get_lesson_quiz` / `submit_lesson_quiz`, миграция платформы 0019
- [x] Домашка: отправка текста/ссылки, история и статусы
- [ ] Домашка: прикрепление файла — ждёт хранилища файлов на платформе
      (веб пока тоже сохраняет только имя файла)
- [x] Тренажёры в WebView с передачей сессии (cookie @supabase/ssr)
- [x] Рейтинг класса (get_class_leaderboard), сертификаты (ссылка на проверку)
- [x] «Ko'nikmalar»: цели по направлениям, уровень (0–100), сколько заданий решено,
      что повторить — `/student/skills`, карточка-ссылка на главной. Данные —
      `objective_mastery` (миграция платформы 0029); до её применения экран
      показывает пустое состояние. Показываются цели, по которым есть практика,
      и цели с `approved`-связью; связь `draft` сама по себе цель не показывает
- [x] «Takrorlash» — ежедневное повторение: карточка «Bugungi takrorlash: N ta savol» на главной,
      экран `/student/review` (до 10 вопросов в день, старые долги первыми, вердикт без
      правильного ответа, итог и серия дней). Данные — RPC `get_review_summary` /
      `get_daily_review` / `submit_review` (миграция платформы 0032); до её применения
      карточка скрыта
- [x] Python-задания урока (платформа 2D): на экране урока карточка «Python mashqlari» открывает
      страницу урока платформы на разделе практики в WebView с сессией ученика — код выполняется
      в браузере (Pyodide), проверяет база. Количество — из `get_lesson_tasks` (задачи типа `code`);
      без задач, без адреса платформы или при ошибке чтения карточка скрыта. Не проверено на
      устройстве: работа Pyodide (Web Worker + WebAssembly) в Android WebView
- [x] Архивированных учеников (profiles.archived_at) не пускать
- [x] Дизайн по брендбуку и макетам: токены в theme.dart (светлая/тёмная тема),
      Baloo 2 / Manrope / JetBrains Mono, иконки Lucide; вход, главная ученика и
      урок — по макетам, остальные экраны — на тех же токенах
