# Релиз в Google Play

Пакет приложения: `uz.aiijodkor.ai_ijodkor`. **После первой загрузки в Play изменить его нельзя** —
если нужно другое имя (например `uz.aiijodkor.app`), скажите до первой загрузки.

## 1. Ключ загрузки (один раз, делает владелец)

Ключ подписи хранится только у владельца и **никогда не попадает в репозиторий**. Потеряете — потеряете
возможность обновлять приложение (в Play App Signing ключ можно сбросить через поддержку, но это долго).

```bash
keytool -genkeypair -v -storetype JKS -keyalg RSA -keysize 2048 -validity 10000 \
  -keystore upload.jks -alias upload
```

Сохраните `upload.jks` и оба пароля в менеджере паролей и сделайте две копии файла в разных местах.

## 2. Секреты репозитория (Settings → Secrets and variables → Actions)

| Секрет | Значение |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | `base64 -w0 upload.jks` (macOS: `base64 -i upload.jks`) |
| `ANDROID_KEYSTORE_PASSWORD` | пароль хранилища |
| `ANDROID_KEY_ALIAS` | `upload` |
| `ANDROID_KEY_PASSWORD` | пароль ключа |
| `SUPABASE_URL` | `https://coojogmncenhkrvytyzz.supabase.co` |
| `SUPABASE_ANON_KEY` | публичный anon-ключ (**не** service_role) |
| `PLATFORM_URL` | адрес сайта платформы |
| `SENTRY_DSN` | необязательно |

## 3. Сборка `.aab`

GitHub → Actions → **Release bundle** → Run workflow. Версия берётся из `pubspec.yaml`
(`version: 1.0.0+1`), либо укажите `build_name` / `build_number` в форме.
**`build_number` должен расти с каждой загрузкой в Play.** Готовый файл — в артефакте
`app-release-aab` (хранится 30 дней). Workflow сам проверяет, что бандл подписан не отладочным ключом.

Локально: положите `android/key.properties` (он в `.gitignore`):

```
storeFile=/полный/путь/upload.jks
storePassword=...
keyAlias=upload
keyPassword=...
```

и `flutter build appbundle --release --dart-define-from-file=dart_defines.json`.

## 4. Play Console (делает владелец)

1. Создать приложение: язык по умолчанию — узбекский, добавить русский.
2. **Play App Signing** — включить (по умолчанию); загрузить `.aab` в «Внутреннее тестирование».
3. Карточка магазина: короткое (до 80 знаков) и полное описание uz/ru, иконка 512×512, баннер 1024×500,
   минимум 2 скриншота телефона.
4. **Политика конфиденциальности** — публичный URL (приложение собирает данные детей: ФИО, успеваемость,
   домашние работы; Sentry получает отчёты об ошибках без персональных данных).
5. «Целевая аудитория»: дети 7–18 → программа Google Play «Для всей семьи» (Families) — потребуются
   политика конфиденциальности, отсутствие рекламы и аналитики в стиле «трекинг ребёнка».
6. «Безопасность данных» (Data safety) и «Рейтинг контента» — заполнить анкеты.
7. Приложение с входом: в «Доступ к приложению» дать проверяющим тестовые логины ученика и учителя
   (отдельные тестовые аккаунты, не настоящие дети).
8. Если аккаунт разработчика личный и создан после ноября 2023, Play требует закрытое тестирование:
   12 тестировщиков в течение 14 дней перед выходом в прод. У организации (ООО) этого требования нет.
9. Порядок: внутреннее тестирование → закрытое → прод.
