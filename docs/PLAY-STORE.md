Izlan — bolalar va o‘smirlar (7–18 yosh) uchun dasturlash va sun’iy intellektni o‘rganish ilovasi. Ilova bilim.aiijodkor.uz platformasi bilan ishlaydi: o‘quvchi, ota-ona va o‘qituvchi bitta hisob orqali kiradi.

Ilovaga kirish uchun markaz bergan login kerak. Reklama yo‘q.

**ru**
Izlan — приложение для обучения программированию и искусственному интеллекту детей и подростков (7–18 лет). Работает с платформой bilim.aiijodkor.uz: ученик, родитель и учитель входят под одной учётной записью.

Ученику: уроки, которые открыл учитель, видео и практические задания; загрузка домашних работ и оценка учителя; баллы, XP, рейтинг месяца и недели; тренажёры (Python, Excel, программирование блоками и другие); сертификаты; мини-игра без интернета.
Родителю: дети, их прогресс, домашние задания и статус оплат — максимально просто.
Учителю: список учеников, проверка работ, выдача доступа к урокам.

Для входа нужен логин, выданный центром. Рекламы нет.

## 2. Целевая аудитория и «Для всей семьи» (Families)
- Аудитория 7–18 → в Play Console отмечаются возрастные группы «до 13» и «13–17/18+» → приложение попадает под **Families Policy** (проверка строже).
- В приложении **нет рекламы**, нет внутренних покупок, нет соцсетей/чатов между детьми.
- Единственный внешний SDK-сборщик данных — **Sentry** (отчёты об ошибках; `sendDefaultPii=false`, персональные данные вычищаются в `sentry_scrub.dart`). ⚠ Для первого релиза безопаснее **не задавать `SENTRY_DSN`**: тогда Sentry вообще не запускается, и вопросов у проверяющих меньше. Включить позже, когда релиз пройдёт модерацию.
- Права: только `INTERNET`. Выбор файла для домашки — системный выбор, без доступа ко всему хранилищу. Камера, микрофон, геолокация, контакты не используются.

## 3. Безопасность данных (Data safety) — черновик ответов
| Вопрос | Ответ |
|---|---|
| Собирает ли приложение данные? | Да |
| Передаются ли данные третьим лицам? | Нет (облачный хостинг базы — обработчик, не «третья сторона для рекламы») ⚠ |
| Шифрование при передаче | Да (HTTPS) |
| Можно ли запросить удаление | Да — по обращению в центр ⚠ нужна страница/форма на сайте |
| Личная информация | ФИО, e-mail/логин, телефон (родитель/ученик) |
| Файлы | Домашние работы, загруженные учеником (файлы, изображения) |
| Действия в приложении | Прогресс уроков, баллы, результаты тестов |
| Финансовая информация | Статус оплат абонемента (платёж в приложении не проводится) ⚠ |
| Диагностика (если включён Sentry) | Отчёты об ошибках без персональных данных |
| Реклама / аналитика | Нет |
Всё «обязательно для работы приложения»; для детей отдельного профилирования нет.

## 4. Рейтинг контента (анкета IARC)
Образовательное приложение: насилия, азартных игр, сексуального контента, продажи товаров нет; общение между пользователями отсутствует; пользовательский контент — только приватные домашние работы, видимые учителю. Ожидаемый рейтинг — «для всех». ⚠ Проверьте формулировки в консоли при заполнении.

## 5. Доступ для проверяющих Google
Приложение закрыто логином → в «Доступ к приложению» укажите **тестовые аккаунты** (ученик, учитель, родитель) на отдельном тестовом классе без настоящих детей и инструкцию: «Введите логин и пароль на первом экране».
