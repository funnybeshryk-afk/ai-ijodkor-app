## 4. Правила работы для агентов (обязательно)

1. **Только через PR.** Никогда не пушить в `main` напрямую. Слияние — только после слова владельца «смержи».
2. **Миграции БД** (`supabase/migrations/NNNN_*.sql`, следующий свободный номер после последнего в `main`):
   агент пишет файл и **не применяет**. Владелец передаёт его на проверку (Claude-ревьюер), затем сам применяет
   в Supabase SQL Editor. PR с миграцией сливается **только после** применения и проверки на проде.
   Каждая миграция: аддитивная, безопасна для повторного запуска, с RLS и тестами в `supabase/tests/rls.test.sql`.
3. **RLS не ослаблять** ради удобства. Правильные ответы тестов ученику не отдавать. `service_role` — только на сервере.
4. Перед работой прочитать этот файл и `CLAUDE.md`/`AGENTS.md` репозитория. Не опираться на старые спеки,
   если они противоречат этому файлу.
5. Если задача неясна или противоречит этому файлу — спросить, а не придумывать.
6. В конце задачи: что сделано, что проверено (tsc/eslint/vitest/flutter test), что **не** проверено,
   есть ли миграция и что нужно от владельца.

## 5. Что есть сейчас (кратко)

**Платформа Bilim:** кабинеты ученика / родителя / учителя / админа; 4 модуля — Digital Start (15 уроков),
AI & Creative (11), Code & Technology (19), Maktab informatikasi (18); тренажёры; домашки с очередью проверки;

пробный доступ на месяц (3 урока трека + тренажёры), заявка на оплату → уведомление владельцу в Telegram;

0056 заявки на оплату).
